# README

This repository rederives the eta form factor from the analysis note that found the most recent branching ratio of eta -> mu+ mu- gamma. It takes the digitized values of plots from the paper, reconstructs the form factor used, then uses it to determine the subsequent eta mass and alpha values used in the paper. In doing so, it shows that the branching ratio value they found needs more up-to-date eta mass and alpha values. This will change the branching ratio used in my analysis of eta -> mu+ mu- (with an eta -> mu+ mu- gamma normalization channel). Finally, these values are calculated, the branching ratio determined, the q^2 (invariant mass square of the dimuon pair) max range reduced, and an optimal value found for minimizing the uncertainty value to serve as the normalization channel for the eta -> mu+ mu- analysis.

The reason this is done is that this normalization channel is expected to be the overwhelming majority source of uncertainty in the measurement of the eta -> mu+ mu- branching ratio. Most of the uncertainty comes at large q^2 values. If we restrict this range and only look at relatively small q^2 values, we can use a form factor whose lambda parameter (which corresponds to the branching ratio uncertainty) has the smallest possible uncertainty value. This also minimizes the uncertainty in the eta -> mu+ mu- branching ratio measurement, thus giving us a potentially novel and competitive measurement and the purpose of this analysis (and, by extension, my thesis).

Analysis paper: "Investigation of the electromagnetic structure of the eta meson in the decay eta -> mu+ mu- gamma" Authors: DJHELYADIN, et. al. Date: 18 June 1980
